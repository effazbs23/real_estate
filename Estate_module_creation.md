# Creating a module on Odoo
1. Created a new directory named 'estate' on the project directory
2. Inside it, created two files named **__init__.py** and **__manifest__.py**. Here,the manifest file describes my module.
3. Written the name of module and dependencies for it inside manifest
4. Created a custom_addons directory inside the odoo directory
5. Defined the addons directory inside it
6. Restarted the odoo server and gone to the update apps list
7. A new module named 'estate' was available there.
